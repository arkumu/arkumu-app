ℹ️ What does this do?

The active schema mapping defines how each organization's data is structured and interpreted:

  • Projekt Snapshot Service uses this to know which datasets/columns contain project data
  • Schema Manifest Service reads this to build CardSchema with property bindings
  • Metadata Entry (if enabled) could validate against this schema

Warning: Changing this may affect data visibility and OAI-PMH exports.
