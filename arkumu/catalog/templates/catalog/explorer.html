What am I looking at?

Think in terms of tables: a Class (Dataset) is your table, each Property is a column, and each Resource corresponds to a cell from the original table. Cell values are stored as literals (strings, numbers, dates), while some columns point to other rows (linked resources) — like a foreign key.

  • Select a Class (Dataset) to choose which rows to explore.
  • Use Facets to filter rows by column values.
  • The Columns Overview shows which columns have the most data (coverage) and how many distinct values they contain.
